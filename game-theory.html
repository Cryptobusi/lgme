Game Theory — Coordination under Floor-first rules

← Back to status · Hederica · Summary

Directive

Treat the lgme rules as a coordination game. Floor stays senior. Named credit, public tape, charge separate, third-seat refusal. An unpublished change is not a change.

Show how the rules change the payoff structure relative to ordinary private or thin-room bargaining.

Core game elements

ElementOrdinary conditionlgme rule
Focal pointPrice or status of the thicker roomFloor (named, senior, untouched)
InformationPrivate or one-sidedPublic tape — every act shown
CredibilityReputation or repeated playThird-seat refusal + constitutive tape
Side paymentsOften folded into the rateCharge named and kept separate
Deviation costLow if unobservedHigh — unpublished change is not a change

Simple 2-player illustration

Players: Giver and Receiver.

Actions: Name the exchange and tape it, or attempt a private/off-tape deal.

  • Both tape → exchange clears at Floor terms; coins move; value recorded.
  • One tapes, one does not → third seat refuses; no line written.
  • Neither tapes → ordinary private deal (possible leakage, no public record).

Under the rules the mutual-tape outcome is the unique equilibrium that survives third-seat refusal. Private deviation yields zero recorded value and can be refused.

Coordination result

The public tape + third-seat refusal converts a multi-equilibrium bargaining game into a single focal equilibrium: name it, show it, clear it at Floor.

Ordinary conditions leave residual, thin-room pricing, and unshown favors. The protocol removes those strategies by making them write nothing.

Result across the earlier mock runs: coins conserved, value only from taped acts, gain versus ordinary capture rate left as a modeling choice.

Parameters used in prior tests

  • Populations: 300 students, 1,000 seniors, 5,000 seniors
  • Horizon: 180 days
  • Services: 50–250 named goods and acts
  • Coins issued relative to prefilled assets
  • All exchanges required to be named and taped

Floor stays senior. Same rules bind state, firm, and person. If it cannot be shown, it is not policy.
