Demographic samples and varied work

Six meaningful demographic samples. Each shows the same nine work types in different mixes. Demonstrative only. Coins conserved. Floor first. Mock runs · Base rate · Desk

Work types used

Tutoring, light care, errands, chores, lending, rides, meal share, groups, check-ins. Weights vary by sample so a school looks different from a nursing home or a neighborhood. Unit values are fixed so the mix, not the price, drives the difference.
