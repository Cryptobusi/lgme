Working with installed HomeBox

Data flow
HomeBox (operational inventory / listing tracker) → CSV or API export → Bigcapital Items / Inventory Adjustments / Expenses.
  1. In HomeBox: Export entities as CSV (/api/v1/entities/export or UI Tools).
  2. Map columns (name, quantity, cost, location, custom fields) to Bigcapital Item import template.
  3. In Bigcapital: Use Import → Items (or Inventory Adjustments) → upload, map, preview, process.
  4. For ongoing sync: script the HomeBox REST API + Bigcapital API (Bearer token).

HomeBox page: /homebox

Docker setup (production)

git clone --depth 1 -b main https://github.com/bigcapitalhq/bigcapital.git
cd bigcapital
cp .env.example .env
# edit .env — set DB passwords, JWT secret, BASE_URL
echo "APP_JWT_SECRET=$(openssl rand -base64 48)" >> .env
docker compose -f docker-compose.prod.yml up -d

Access at the configured BASE_URL (default port 80/443 via proxy). Create organization and admin user on first load.

Functional test checklist (preview)

1. Deploy & login — Stack starts, create org + user, dashboard loads.
2. Chart of accounts — Default accounts present; add custom asset/expense accounts for listing costs.
3. Items import — Upload sample HomeBox-style CSV of items; map name/qty/cost; preview shows correct rows; process succeeds; items appear in inventory list with valuation.
4. Manual transaction — Create expense (e.g. listing fee) and invoice; journal entries balance.
5. Reports — P&L and Balance Sheet generate for the period; inventory valuation matches imported quantities.
6. API smoke — Generate API key; GET /api/items and /api/reports/profit-loss-sheet return 200 with Bearer auth.
7. HomeBox round-trip — Export from HomeBox, import to Bigcapital, confirm totals match; re-export from Bigcapital if needed.
