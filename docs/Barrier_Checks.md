# Barrier checks — 11 October 2026

Test applied: Can this extraction or relaxation be completed without a prior, public, categorical commitment that binds every seat equally and leaves a checkable mark?

If yes, the barrier is incomplete. Leaks: same party benefits and waives; category redefinition; private window; untitled zero; quieter seat; instant private amendment.

## 1. New residual claim or “fee adjustment”

**Result: Incomplete if unstructured.**  
A residual or fee that can be named after the fact, or reclassified from remainder, can be completed by the present self without a prior locked commitment.  
**Leak:** category redefinition + possible private timing.  
**Close:** Charge/risk must be posted and locked before any paper is written; remainder (including zero) must be titled on the tape before it can move. An adjustment that does not appear as a prior named line writes nothing.

## 2. Emergency or off-schedule mint window

**Result: Incomplete if unstructured.**  
An emergency window opened at the moment of need lets the present self time extraction.  
**Leak:** private window + instant amendment.  
**Close:** No off-schedule mint. Any exception must be pre-declared, auto-expiring, invoked only by recorded act, and still subject to Floor-first and titled remainder. Silence or urgency does not create a window.

## 3. Change to the Floor Basket amount or seniority

**Result: Holds if amendment path is used; incomplete if instant.**  
Altering Floor seniority or amount at the moment it is inconvenient bypasses the barrier.  
**Leak:** instant private amendment.  
**Close:** Floor remains senior by rule. Any change travels a slower, scheduled, recorded path that itself leaves a tape entry and cannot be exploited in the same act. Until that path is completed, the prior Floor stands.

## 4. Agent action that moves value

**Result: Holds when agent is clerk only.**  
An agent that can mint, waive Floor, or move untitled residual acts as a present self with authority.  
**Leak:** quieter seat or surrender of the barrier to the agent.  
**Close:** Agent applies already-named rules (Floor first, public schedule, titled remainder). It does not originate print or residual. Every agent act is a tape line. Missing required lines write nothing.

## 5. Proposed exception for one seat (state, firm, or person)

**Result: Incomplete.**  
A quieter path for any single seat re-creates time-inconsistency for that actor.  
**Leak:** asymmetric / quieter seat.  
**Close:** Identical categorical rules bind state, firm, and person. No private window, no untitled residual, no off-tape adjustment for any seat. Symmetry is itself a bright-line rule.

## Summary

All five cases fail the test if left unstructured. Each is closed by enforcing prior naming, default-closed silence, mechanical Floor seniority, constitutive tape, symmetric seats, and slower recorded amendment. No case currently possesses a remaining private path once those constraints are applied.

Floor stays senior. Same rules bind all three. An unpublished change is not a change.
