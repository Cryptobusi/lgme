# Precommitment (Schelling) — one page

Preferences reverse. The self that wants restraint today will often want extraction tomorrow. Intention alone fails. The remedy is an external barrier set in advance.

## What works
- Remove or heavily friction the undesired option
- Use bright-line rules (“untitled remainder is not a remainder”)
- Default to closed (omission writes nothing)
- Force naming before any claim (charge, risk, remainder including zero)
- Make the record constitutive (“unpublished change is not a change”)
- Apply senior claims mechanically where possible
- Bind every seat with the identical path
- Allow change only through a slower, recorded route

## Test
Can this extraction or relaxation be completed without a prior, public, categorical commitment that binds every seat equally and leaves a checkable mark?
If yes, the barrier is incomplete.

## Leaks
Same party benefits and waives; category redefinition; private window; untitled zero; quieter seat; instant private amendment.

## Already present in the order
Floor → public mint → named issue → tape → named charge → titled residual (including zero), plus seat symmetry and “unpublished change is not a change.”
Jefferson: people hold final authority but alterations travel the public path.
Marcum & Smith: humility, curiosity, veracity reduce quiet redefinition.

## Use
Run any new window, fee, residual, or exception through the test and the leak list before it operates. Show one small case in which a missing line writes nothing and the same case applies to each seat. That transmits the barrier as structure.

Citation: Schelling, Thomas C. 1978. “Egonomics, or the Art of Self-Management.” *American Economic Review* 68(2): 290–294.
