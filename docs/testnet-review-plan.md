# Testnet review before any mainnet go-live

This note is not a public page. Mainnet writes stay off until the owner accepts a completed review from a real member on a real phone.

The checklist lives at `/testnet-review?invite=testnetrev`. It is `noindex`, omitted from the sitemap, and disallowed in `robots.txt`. Results stay in `lgme.testnet.review` on that phone. Export writes a file the tester chooses. The page does not send it.

## Acceptance

Every line below is required. A missing line keeps mainnet closed.

1. The tester is a real member, not a mock author, and the phone is their own.
2. The installed app opens from the icon.
3. Email sign-in works, and the server stores only the code hash.
4. The $1 setup fee is paid once from the pool and once self-paid, both on testnet, from a live quote.
5. The member lists one Health offer and one Health request. Both stay test until a real claim replaces them.
6. The two listings match. A trainer confirms. Both people confirm. An IdidIt receipt is a hash only.
7. One trade over $100 stays pending until three attestations.
8. The member sponsors one person.
9. The member opens one dispute. The topic message is a hash, not a statement, unless both people consent to share.
10. The member RSVPs to a circle session and checks in.
11. The personal Health board is visible on that phone and is not posted.
12. With the network off, the installed app still opens the board from the saved shell.
13. Declined, cancelled, expired, disputed, partial, repeat, circle, pool-sponsored, and self-paid are real listing types. The 15 Health examples use them and stay labeled test.
14. Gym cards and repair bodies reject unknown nested keys.
15. The exported review file is the record the owner accepts. No mainnet topic is created and no mainnet transaction is sent as part of this review.
