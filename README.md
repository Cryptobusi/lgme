# lgme.app

Egonomic live performance. The book at egonomicanonymous.live is stopped. Future performances are recorded in `performance.json`, newest last in the file and newest first on the page.

## Start

- GitHub: Cryptobusi/lgme, branch `main`
- Vercel team: `lgme`
- Domain: `lgme.app`
- This site does not hold keys, does not send a desert, and does not run the amend.

## A new performance

Append one object to `performances`:

```json
{ "at": "YYYY-MM-DD", "n": "02", "place": "lgme.app", "act": "What was done, in one sentence." }
```

Push to `main`. The page is the record.
