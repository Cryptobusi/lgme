What a visit sends

Opening a page on lgme.app can send one note a day to the owner. This page says what is in that note, and what this site does not do with it.

What is logged

The note names the page path and query, the time in New York and in UTC, and the referrer. It names the country, region, and city from the network headers. The network address is masked: an IPv4 address keeps the last piece as 0, and an IPv6 address keeps the first three groups. The note includes the user agent, a short device and browser line, and the language header.

A first-party cookie named va_seen remembers this browser for 24 hours, so the same browser does not send another note until that day is over. Bots and crawlers are not sent. If the mail key is not set, nothing is sent.

Why, and how long it is kept

The note is so the owner can see that a person opened a page. It is email. It stays in the owner's inbox until the owner deletes it.

The site does not sell that note. It does not share it. It does not use it for ads.

What does not change

Solana wallet checks and the Exchange keep the data practices they already have. This page does not change them. It does not move funds, and it does not change Campus, mutual credit, or the view switcher.

The first time this browser loads the desk, a small notice offers this page. Dismiss saves that choice on this device only.
