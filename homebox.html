HomeBox for Exchange Listing Coordination

Self-hosted inventory system adapted to gather, organize, and keep up-to-date the information required for exchange listing of $LGME / related instruments. Coordinates documents, statuses, and notifications. Floor stays senior. An unpublished change is not a change.

What HomeBox provides

HomeBox (sysadminsmedia/homebox) is a lightweight, self-hosted Go app for tracking items, locations, documents, warranties, and maintenance. We use its structure for the listing book:

  • Locations = listing stages (Pre-submission, Legal, Technical, Marketing, Live)
  • Items = required documents / assets (whitepaper, legal opinion, KYC pack, liquidity plan, etc.)
  • Custom fields + attachments for versions and status
  • Maintenance schedules → automated reminders for expiry or review dates
  • Search + QR codes for quick retrieval
  • API keys for future automation / notifications

Notifications & coordination

HomeBox maintenance tracking can flag upcoming review dates. For automated external notifications:

  • Use the REST API + API keys to poll status
  • Pair with a simple cron or GitHub Action that checks for changes and posts to Discord / X / email
  • Or self-host HomeBox and point its health/maintenance endpoints at an existing notifier

Setup guide (Docker):

openssl rand -base64 48 > hbox.pepper
docker run -d --name lgme-homebox --restart unless-stopped \
  -p 3100:7745 \
  -e HBOX_AUTH_API_KEY_PEPPER=$(cat hbox.pepper) \
  -v /path/to/lgme-listing-data:/data \
  ghcr.io/sysadminsmedia/homebox:latest

Then open http://localhost:3100, create an account, and start adding locations + items.
